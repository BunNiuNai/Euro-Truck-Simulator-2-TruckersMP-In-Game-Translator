# ETS2 翻译器 v1.7.0 — 广告发送器集成设计文档

> 日期: 2026-07-21 | 版本: v1.7.0

---

## 概述

将 TMP 广告软件 (Java Swing) 的全部功能用 Python/Tkinter 复刻，作为翻译器设置面板的新 Tab「📢 广告发送」。

---

## 架构

```
main.py SettingsDialog (6 tabs)
  ├── API 配置         (现有)
  ├── 快捷键           (现有)
  ├── 外观             (现有)
  ├── 翻译器日志       (现有)
  ├── 消息日志         (现有)
  └── 📢 广告发送      (v1.7.0 新增)
```

### 数据流

```
config.py (持久化)
  ├── ad_messages: list[str]     # 5条消息内容
  ├── ad_countdown: str          # 倒计时分钟数 (字符串)
  │
  ▼
_ad_tab UI  ←→  config
  │
  │ 用户点"开始"
  ▼
_ad_scheduler (root.after 定时器)
  │  每秒递减 countdown_seconds
  │  归零 → 发消息 → 重置
  │
  ▼
input_sender.send_chat_message()
  (复用翻译器现有 SendInput 键盘模拟)
```

## 新增配置字段 (config.py)

```python
# AppConfig 新增
ad_messages: list[str] = field(default_factory=lambda: [""] * 5)  # 5条广告消息
ad_countdown: str = ""        # 倒计时分钟数

# 运行时状态（不持久化，仅在 _ad_tab 内管理）
# - _ad_running: bool = False
# - _ad_countdown_seconds: int = 0
# - _ad_current_index: int = 0
# - _ad_timer_after_id: str | None = None
```

**注意**: `ad_messages` 和 `ad_countdown` 需要持久化到 config.json，自动保存/恢复。

### 核心方法

| 方法 | 职责 |
|:---|:---|
| `_build_ad_tab()` | 构建全部 UI 组件 |
| `_ad_start()` | 校验 → 初始化定时器 → 高亮 → 写日志 |
| `_ad_stop()` | 取消定时器 → 清零 → 去高亮 |
| `_ad_tick()` | 每秒递减,归零调用 `_ad_send_current()` |
| `_ad_send_current()` | 取当前消息 → `threading.Thread` 调用 `send_chat_message()` |
| `_ad_highlight(index)` | 高亮第 index 行,去高亮其他 |
| `_ad_append_log(text)` | 追加日志 + 500行裁剪 |

---

## 发送流程

```
_ad_tick() — 在主线程 (每1秒)
  countdown_seconds--
  if countdown_seconds <= 0:
    threading.Thread → _ad_send_current()
                       │
                       ├─ 跳过空消息 (自动跳到下一条)
                       │
                       ├─ send_chat_message(text, "y")
                       │    Y→0.5s→Ctrl+V→0.5s→Enter
                       │
                       ├─ root.after(0, _ad_append_log)
                       │
                       └─ root.after(0, _ad_highlight(next))
    countdown_seconds = total_seconds  # 重置
```

## UI 样式规范

沿用 `SettingsDialog` 现有配色体系:
- 卡片: `_CARD_BG (#2d2d30)`, `_CARD_BORDER (#3e3e42)`
- 文字: `_TEXT (#cccccc)`, `_TEXT_SEC (#858585)`
- 强调: `_ACCENT (#007acc)`, `_GREEN (#4ec9b0)`, `_RED (#f44747)`
- 输入框: `_INPUT_BG (#252526)`
- 高亮色: `#fff3cd` (黄色背景,与 Java 版一致)
- 彩色圆点: 红 `#e74c3c`, 橙 `#e67e22`, 绿 `#3cb371`, 蓝 `#4090e0`, 紫 `#9b59b6`

按钮沿用 `_pill_btn()` 样式,但增加绿/红色变体:
- 开始: 绿色背景 `#3cb371` → hover `#2e965a`
- 暂停: 红色背景 `#e74c3c` → hover `#c0392b`
